## The rule

For agent-driven or sandboxed invocations, use `./gradlew-nix <args>`
instead of `./gradlew <args>`. The wrapper runs the nix-provided
`gradle` (pinned by `flake.nix` to the same version as
`gradle/wrapper/gradle-wrapper.properties`, currently 8.14.4) inside
`nix develop`, so:

- No system JDK is required on PATH — nix provides JDK 21 + Gradle.
- No wrapper-zip download is attempted, so network-restricted sandboxes
  do not fail on `services.gradle.org` lookups.
- The same flake.nix that the rest of the repo uses provides the
  toolchain, so versions stay in sync.

If the executing environment forbids writes to `~/.gradle/` (typical
sandbox restriction), **also** export `GRADLE_USER_HOME` to a writable
path before invoking:

```bash
GRADLE_USER_HOME="$TMPDIR/gradle-home" ./gradlew-nix :core:allTests
```

`$TMPDIR` is set by the agent harness to a sandbox-writable temp dir.

## Why this shape

`./gradlew` on a machine without a system JDK fails with
`Unable to locate a Java Runtime`. Running it inside `nix develop`
(`nix develop --command ./gradlew ...`) gets past the JDK problem but
then the wrapper insists on downloading
`gradle-8.14.4-bin.zip` into `~/.gradle/wrapper/dists/...`. Both the
download (network) and the write (filesystem) are typically blocked in
agent sandboxes.

Calling the nix-provided `gradle` directly side-steps both problems:
nix already has the matching distribution in the store, so the wrapper
machinery isn't needed.

`gradlew` itself is regenerated by `gradle wrapper`, so patching it
in-place would not survive a wrapper-version bump. A sibling script
(`gradlew-nix`) leaves the canonical wrapper pristine.

## What NOT to do

- Do not edit `gradlew` to call nix — it is regenerated by
  `gradle wrapper` and edits will be lost on the next wrapper bump.
- Do not assume `./gradlew` works in agent shells; it requires a
  system JDK and writable `~/.gradle/`.
- Do not skip the `GRADLE_USER_HOME` override in a sandbox; without
  it the daemon's cache writes will fail.

## Anchors

- Wrapper script: `gradlew-nix` (repo root)
- Toolchain source: `flake.nix` (`jdk21` + `gradle.override { java = jdk; }`)
- Wrapper version pin: `gradle/wrapper/gradle-wrapper.properties`
